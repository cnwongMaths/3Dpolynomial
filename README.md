# 多項式戰機 — 運算與因式分解

在暴雨霓虹的賽博朋克城市峽谷中駕駛戰機，重溫中學數學「多項式」一課。
每道題目的三個答案由三架無人機攜帶——讀題、瞄準、射中正確答案得分；
射錯系統離線 2 秒、連擊歸零；撞上高樓則墜毀重生。3 分鐘限時特訓，
結算顯示分數、答對/答錯、準確率與最佳連擊。

完全自包含、單機：沒有伺服器、沒有構建步驟、沒有網絡請求——只有普通
靜態文件和 ES 模組。課題、畫質與聲音設置存在 `localStorage`。

## 課題（主選單可切換）

- **混合特訓** —— 以下全部隨機混合
- **多項式乘法** —— 單項式×多項式、(ax+b)(cx+d)、(ax+b)² 展開
- **因式分解** —— 提取公因式、平方差、完全平方、十字相乘法
- **多項式加減** —— 合併同類項（含減法變號陷阱）
- **指數定律** —— aᵐ×aⁿ、aᵐ÷aⁿ、(aᵐ)ⁿ、(kaᵐ)ⁿ

誘答全部針對常見錯誤設計（忘記變號、漏中項、指數誤乘等）。

## 運行

任意靜態文件伺服器（ES 模組需要 `http://`，不能用 `file://`）：

```sh
python3 -m http.server 8000
# 然後打開 http://localhost:8000/
```

桌面版 Chrome/Edge/Safari，WebGL2；亦支援觸控裝置。

## 操作

| 輸入 | 動作 |
| --- | --- |
| 滑鼠 / 觸控拖動 | 轉向 |
| 左鍵 / J / 「開火」鈕 | 發射（按住連發） |
| W / S | 加速 / 減速 |
| Shift / 「加速」鈕 | 推進加速（會過熱） |
| 空格 | 垂直點火拉升 |
| Esc / 「II」鈕 | 暫停 |

## 技術

Three.js r170（import map，無打包器）、自定義 HDR 後處理鏈、平面反射濕滑
街面、程序化霓虹城市（480 米無縫循環）、GPU 雨絲、WebAudio 合成音效。
題目由 `js/arena/mathquiz.js` 程序化生成；答案無人機在 `js/arena/drones.js`。
